# v0.1.0-alpha.2 — reproducible source/BYO development preview

This prerelease supersedes alpha.1 with a byte-reproducible source archive and current GitHub Actions runtimes. It is **not a ready-to-play PortMaster ZIP**.

## What changed since alpha.1

- source ZIP timestamps are normalized to UTC;
- CI proves that UTC and Pacific/Honolulu produce byte-identical ZIPs;
- the per-file hash manifest is verified against an extracted archive;
- the public alpha.1 ZIP was independently reproduced with SHA-256 `a22bab833fa580e35e4d9852066d87cc2e3e8cba96bec9b01bfd4e6111381e21`;
- the Node test harness supports Node 22+ read-only global `navigator` properties;
- `actions/checkout` is updated to v7;
- `softprops/action-gh-release` is updated to v3.0.2.

## What is included

- PLAYABLE-V2 canonical source and artifact contracts;
- native WPE launcher/backend, gamepad and PLAYPAIR audio-mixer sources;
- deterministic Construct 2 port-layer tooling;
- source/BYO preview ZIP with archive and per-file SHA-256 manifests;
- CI gates for scripts, audio behavior, PLAYABLE-V2 hashes, assets, secrets and private infrastructure;
- contributor, security, conduct and compatibility-report templates;
- documented device evidence and known limitations.

## What is not included

- commercial Moonrider game files;
- `data.js`, `c2runtime.js`, media, artwork, audio, video or executables from the game;
- a WPE binary runtime;
- claims of compatibility beyond the tested RG40xx H / muOS configuration.

## Why the runtime is absent

The available binary candidate failed the redistribution audit because it has 185 ELF files but no bundled license set, source provenance or third-party component manifest. It also predates PLAYABLE-V2 and would regress the solved GLX path. See `reports/RUNTIME-REDISTRIBUTION-AUDIT-20260715.md` and issue #2.

## Known limitations

- approximately 23 fps in observed gameplay;
- slowdowns to 7 and 13 fps;
- WebProcess input acknowledgements delayed up to 1.79 s during a captured slowdown;
- historical gamepad snapshots can produce phantom simultaneous buttons;
- only one handheld/firmware combination has been tested.

See `KNOWN_ISSUES.md` and issue #3 before testing.

## Artifact verification

Download the source ZIP, the per-file hash manifest and `SHA256SUMS`, then run:

```sh
sha256sum -c SHA256SUMS
unzip Moonrider-PortMaster-0.1.0-alpha.2-source.zip
sha256sum -c Moonrider-PortMaster-0.1.0-alpha.2-source-files.sha256
```

To reproduce the ZIP from the tag:

```sh
OUT_DIR=/tmp/moonrider-alpha2 SOURCE_REF=v0.1.0-alpha.2 \
  VERSION=v0.1.0-alpha.2 bash scripts/make-source-preview.sh
```
